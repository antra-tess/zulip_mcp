- Incoming stream messages now include a short active-topics hint and structured topic names, optional live-observed last-message times and current-topic markers. `ZULIP_ACTIVE_TOPICS` defaults to 6 (`0` disables; maximum 50). Background refreshes use a bounded per-stream LRU cache; cold caches and API failures never delay delivery. Names are quoted and clipped in text, shown once per `ZULIP_ACTIVE_TOPICS_TTL_MS` window (default 60000) or ordered-name-list change; metadata accompanies every warm event. Refreshes cost one topics GET, with a four-request cap and shared rate-limit cooldown. Move/rename/resolve/delete events invalidate stale lists. DMs are unchanged.
